# 系统软件

## 脚本程序

### 目录遍历脚本

!!! example 使用`os.walk`遍历指定目录及其所有子目录的文件

```python
import os                   # 导入操作系统模块，用于操作文件/文件夹

def list_files(directory):
    # 遍历指定目录(包括所有子文件夹)
    # root: 当前文件夹路径
    # dirs: 当前文件夹里的子文件夹
    # files: 当前文件夹里的文件

    for root, dirs, files in os.walk(directory):
        for file in files:
            # 拼接完整路径并打印：文件夹路径 + 文件名
            print(os.path.join(root, file))

if __name__ == "__main__":
    list_files('.')         # 运行：遍历 [当前目录] 下所有文件
```

### 执行系统命令

!!! example 执行系统命令并捕获输出。

```python
import subprocess               # Python内置的系统命令调用模块

def run_command(command):
    # 执行系统命令，并捕获输出/错误信息
    result = subprocess.run (command, shell=True, text=True, capture_output=True)
    # 打印命令的正常输出
    print(f"STDOUT: \n{result.stdout}")
    # 打印命令的错误信息(如果执行失败)
    print(f"STDERR: \n{result.stderr}")

if __name__ == "__main__":
    # 示例：执行 ls 命令
    run_command(["ls -al"])
```
