# 关键路径

关键路径问题是工程管理中的经典问题。假设你要建造一栋房子，需要完成地基、框架、屋顶、水电等多个任务，每个任务都有预计的工期，而且任务之间有先后依赖关系（比如必须先打地基才能建框架）。整个工程最短需要多少天？哪些任务一旦延误就会影响整体进度？这两个问题分别对应**关键路径**的"总工期"和"关键活动"。

## 1 AOE 网

**AOE 网（Activity On Edge）**是用有向无环图（DAG）表示工程进度的模型：

- **顶点**：表示事件（event），即某个时间点
- **边**：表示活动（activity），边上的权重表示完成该活动所需的时间
- 入度为 0 的顶点：工程的起点
- 出度为 0 的顶点：工程的终点

```
    A ──3──→ B ──2──→ D ──4──→ E
     \                ↑         ↑
      └──5──→ C ──3──┘         │
             └────────6─────────┘

顶点 A 是起点，E 是终点。
边 A→B 表示一个活动，需要 3 天。
```

AOE 网需要解决的两个核心问题：

1. **工程至少需要多少时间才能完成？** → 最长路径的长度
2. **哪些活动是"关键"的（不能延误）？** → 时差为 0 的活动

## 2 最早开始时间（VE）

**最早开始时间 VE（Vertex Earliest time）** 表示从起点到该顶点的最长路径长度，也就是该事件最早可以在什么时间发生。

计算 VE 需要按照**拓扑排序**的顺序从前向后推导：

```
VE[起点] = 0
VE[v] = max(VE[u] + weight(u, v)) 对所有前驱 u
```

**逐步示例**：以下图为例计算 VE

```
     0 ──3──→ 1 ──2──→ 3 ──4──→ 5
     │         │                  ↑
     2         3                  │
     ↓         ↓                  │
     2 ──1──→ 4 ──────5──────────┘
```

| 拓扑序 | 顶点 | 前驱 | VE 计算 | VE 值 |
|---|---|---|---|---|
| 1 | 0 | 无（起点） | VE[0] = 0 | 0 |
| 2 | 1 | 0 | VE[1] = VE[0] + 3 = 3 | 3 |
| 3 | 2 | 0 | VE[2] = VE[0] + 2 = 2 | 2 |
| 4 | 3 | 1 | VE[3] = VE[1] + 2 = 5 | 5 |
| 5 | 4 | 2, 1 | VE[4] = max(VE[2]+1=3, VE[1]+3=6) = 6 | 6 |
| 6 | 5 | 3, 4 | VE[5] = max(VE[3]+4=9, VE[4]+5=11) = 11 | 11 |

总工期 = 11

```python
from collections import deque, defaultdict

def compute_ve(n, graph, indegree):
    """
    计算每个顶点的最早开始时间 VE
    
    参数:
        n: 顶点数
        graph: 邻接表，graph[u] = [(v, weight), ...]
        indegree: 入度数组
    
    返回:
        ve: 最早开始时间数组
        topo_order: 拓扑排序结果（用于后续计算 VL）
    """
    ve = [0] * n
    queue = deque([i for i in range(n) if indegree[i] == 0])
    topo_order = []

    while queue:
        u = queue.popleft()
        topo_order.append(u)

        for v, w in graph[u]:
            # 更新 v 的最早开始时间：取所有前驱中的最大值
            if ve[u] + w > ve[v]:
                ve[v] = ve[u] + w

            indegree[v] -= 1
            if indegree[v] == 0:
                queue.append(v)

    return ve, topo_order
```

## 3 最晚开始时间（VL）

**最晚开始时间 VL（Vertex Latest time）** 表示在不影响整个工程工期的前提下，该事件最晚可以在什么时间发生。

计算 VL 需要**反向拓扑排序**，从终点向起点推导：

```
VL[终点] = VE[终点]（整个工程的工期）
VL[u] = min(VL[v] - weight(u, v)) 对所有后继 v
```

**逐步示例**：接上例，总工期 = 11

| 反向拓扑序 | 顶点 | 后继 | VL 计算 | VL 值 |
|---|---|---|---|---|
| 1 | 5 | 无（终点） | VL[5] = VE[5] = 11 | 11 |
| 2 | 3 | 5 | VL[3] = VL[5] - 4 = 7 | 7 |
| 3 | 4 | 5 | VL[4] = VL[5] - 5 = 6 | 6 |
| 4 | 1 | 3, 4 | VL[1] = min(VL[3]-2=5, VL[4]-3=3) = 3 | 3 |
| 5 | 2 | 4 | VL[2] = VL[4] - 1 = 5 | 5 |
| 6 | 0 | 1, 2 | VL[0] = min(VL[1]-3=0, VL[2]-2=3) = 0 | 0 |

**关键活动判定**：ve[u] + weight == vl[v]

| 边 | ve[u] | +w | == | vl[v] | 关键？ |
|---|---|---|---|---|---|
| 0→1 | 0 | +3 | 3 | 3 | ✓ |
| 0→2 | 0 | +2 | 2 | 5 | ✗ |
| 1→3 | 3 | +2 | 5 | 7 | ✗ |
| 1→4 | 3 | +3 | 6 | 6 | ✓ |
| 2→4 | 2 | +1 | 3 | 6 | ✗ |
| 3→5 | 5 | +4 | 9 | 11 | ✗ |
| 4→5 | 6 | +5 | 11 | 11 | ✓ |

关键路径：0 → 1 → 4 → 5，总工期 = 11

```python
def compute_vl(n, graph, ve, topo_order):
    """
    计算每个顶点的最晚开始时间 VL
    
    参数:
        n: 顶点数
        graph: 邻接表
        ve: 最早开始时间
        topo_order: 拓扑排序结果
    
    返回:
        vl: 最晚开始时间数组
    """
    max_time = max(ve)          # 整个工程的总工期
    vl = [max_time] * n         # 初始化为最大值

    # 反向遍历拓扑排序，从后往前推导
    for u in reversed(topo_order):
        for v, w in graph[u]:
            # u 的最晚时间 = 所有后继中的最小值
            if vl[v] - w < vl[u]:
                vl[u] = vl[v] - w

    return vl
```

## 4 关键活动与关键路径

**关键活动**是指最早开始时间和最晚开始时间相等的活动（即没有机动时间）。用公式表示：对于边 (u, v)，如果 `ve[u] + w == vl[v]`，则活动 (u, v) 是关键活动。

所有关键活动组成的路径就是**关键路径**。

```python
def find_critical_activities(n, graph, ve, vl):
    """
    找出所有关键活动
    
    一条边 (u, v) 是关键活动的条件：
    ve[u] + weight(u, v) == vl[v]
    
    也就是说，这个活动没有"机动时间"——
    最早做它和最晚做它的时间一样，延误就会拖慢整个工程。
    
    返回:
        critical_edges: 列表，每个元素为 (u, v) 表示一条关键活动
    """
    critical_edges = []
    for u in range(n):
        for v, w in graph[u]:
            if ve[u] + w == vl[v]:
                critical_edges.append((u, v))
    return critical_edges


def print_critical_paths(n, graph, ve, vl):
    """
    输出关键路径上的所有活动
    """
    # 找到关键活动
    critical_edges = find_critical_activities(n, graph, ve, vl)

    # 关键活动构成的子图
    critical_graph = defaultdict(list)
    for u, v in critical_edges:
        critical_graph[u].append(v)

    # DFS 输出所有关键路径
    def dfs(u, path):
        path.append(u)
        if u not in critical_graph or not critical_graph[u]:
            # 到达终点，打印路径
            print(' -> '.join(map(str, path)))
        else:
            for v in critical_graph[u]:
                dfs(v, path)
        path.pop()

    for i in range(n):
        # 从没有前驱的关键活动开始打印
        has_predecessor = False
        for u in critical_graph:
            if i in critical_graph[u]:
                has_predecessor = True
                break
        if not has_predecessor:
            dfs(i, [])
```

### 完整算法

```python
from collections import deque, defaultdict

def critical_path_method(n, edges):
    """
    关键路径法（CPM）完整实现
    
    参数:
        n: 顶点数
        edges: 边列表，每个元素为 (u, v, w)
    
    返回:
        max_time: 工程总工期
        critical_edges: 关键活动列表
    """
    # 建图
    graph = defaultdict(list)
    indegree = [0] * n
    for u, v, w in edges:
        graph[u].append((v, w))
        indegree[v] += 1

    # 第一步：拓扑排序，计算 VE
    ve, topo_order = compute_ve(n, graph, indegree[:])

    # 如果拓扑序列长度不够，说明图中有环
    if len(topo_order) != n:
        return -1, []

    # 第二步：反向推导，计算 VL
    vl = compute_vl(n, graph, ve, topo_order)

    # 第三步：找出关键活动
    critical_edges = find_critical_activities(n, graph, ve, vl)

    return max(ve), critical_edges
```

## 5 编程题目

### 5.1 关键路径长度（sy404）

关键路径，https://sunnywhy.com/sfbj/10/7/404

给定一个有向无环图，求从起点到终点的关键路径长度（最长路径长度）。

**输入**：第一行两个整数 n、m（顶点数、边数）。接下来 m 行，每行三个整数 u、v、w，表示一条从 u 到 v 的有向边，权值为 w。

**输出**：一个整数，表示关键路径的长度。

```python
from collections import deque, defaultdict

def critical_path_length(n, edges):
    """求关键路径长度（最长路径）"""
    graph = defaultdict(list)
    indegree = [0] * n

    for u, v, w in edges:
        graph[u].append((v, w))
        indegree[v] += 1

    ve = [0] * n
    queue = deque([i for i in range(n) if indegree[i] == 0])

    while queue:
        u = queue.popleft()
        for v, w in graph[u]:
            if ve[u] + w > ve[v]:
                ve[v] = ve[u] + w
            indegree[v] -= 1
            if indegree[v] == 0:
                queue.append(v)

    return max(ve)
```

示例输入：
```
6 8
0 1 3
0 2 2
1 3 2
1 4 3
2 3 4
2 5 1
3 5 2
4 5 1
```

示例输出：
```
8
```

### 5.2 关键活动（sy405）

关键路径，https://sunnywhy.com/sfbj/10/7/405

找出 AOE 网中的所有关键活动。

**输入**：第一行两个整数 n、m（顶点数、边数）。接下来 m 行，每行三个整数 u、v、w，表示一条有向边。

**输出**：关键活动的数量，以及每个关键活动的起点和终点。

```python
from collections import deque, defaultdict

def find_critical(n, edges):
    """找出关键活动"""
    graph = defaultdict(list)
    indegree = [0] * n

    for u, v, w in edges:
        graph[u].append((v, w))
        indegree[v] += 1

    # VE
    ve = [0] * n
    queue = deque([i for i in range(n) if indegree[i] == 0])
    topo = []

    while queue:
        u = queue.popleft()
        topo.append(u)
        for v, w in graph[u]:
            if ve[u] + w > ve[v]:
                ve[v] = ve[u] + w
            indegree[v] -= 1
            if indegree[v] == 0:
                queue.append(v)

    # VL
    max_time = max(ve)
    vl = [max_time] * n
    for u in reversed(topo):
        for v, w in graph[u]:
            if vl[v] - w < vl[u]:
                vl[u] = vl[v] - w

    # 关键活动：ve[u] + w == vl[v]
    critical = [(u, v) for u in range(n) for v, w in graph[u] if ve[u] + w == vl[v]]
    return critical
```

示例输入：
```
6 8
0 1 3
0 2 2
1 3 2
1 4 3
2 3 4
2 5 1
3 5 2
4 5 1
```

示例输出：
```
4
0 2
1 4
2 3
3 5
```

### 5.3 关键路径（sy406）

关键路径，https://sunnywhy.com/sfbj/10/7/406

输出 AOE 网的关键路径。

**输入**：第一行两个整数 n、m（顶点数、边数）。接下来 m 行，每行三个整数 u、v、w。

**输出**：关键路径上的顶点序列。

```python
from collections import deque, defaultdict

def find_critical_path(n, edges):
    """输出关键路径"""
    graph = defaultdict(list)
    indegree = [0] * n

    for u, v, w in edges:
        graph[u].append((v, w))
        indegree[v] += 1

    ve = [0] * n
    queue = deque([i for i in range(n) if indegree[i] == 0])
    topo = []

    while queue:
        u = queue.popleft()
        topo.append(u)
        for v, w in graph[u]:
            if ve[u] + w > ve[v]:
                ve[v] = ve[u] + w
            indegree[v] -= 1
            if indegree[v] == 0:
                queue.append(v)

    max_time = max(ve)
    vl = [max_time] * n
    for u in reversed(topo):
        for v, w in graph[u]:
            if vl[v] - w < vl[u]:
                vl[u] = vl[v] - w

    # 关键路径上的顶点：ve[u] == vl[u]
    # 按拓扑序输出
    path = [i for i in topo if ve[i] == vl[i]]
    return path
```

示例输入：
```
6 8
0 1 3
0 2 2
1 3 2
1 4 3
2 3 4
2 5 1
3 5 2
4 5 1
```

示例输出：
```
总工期: 8
关键路径: 0 -> 2 -> 3 -> 5
```

## 本章小结

- **AOE 网**用顶点表示事件、边表示活动，边权为活动耗时
- **VE（最早开始时间）**：拓扑序正向推导，取前驱中的最大值
- **VL（最晚开始时间）**：拓扑序反向推导，取后继中的最小值
- **关键活动**：`ve[u] + w == vl[v]`，即没有机动时间的活动
- **关键路径**：所有关键活动组成的路径，决定工程总工期
- 关键路径的长度就是 AOE 网中**最长路径**的长度
- 关键路径法不仅用于工程管理，还广泛应用于项目排期、生产调度等场景
