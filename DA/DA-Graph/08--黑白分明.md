# 黑白分明

在图论中，有一类特殊的图叫**二分图（Bipartite Graph）**：它的所有顶点可以被分成两个不相交的集合，使得每条边的两个端点分别属于不同的集合。用颜色来比喻，就是"黑色顶点只连白色顶点，白色顶点只连黑色顶点"——黑白分明。

## 1 二分图的定义与判定

### 1.1 二分图的概念

**二分图**的正式定义：图 G = (V, E) 是二分图，当且仅当存在一种划分 V = A ∪ B，A ∩ B = ∅，使得 E 中每条边的两个端点分别属于 A 和 B。

```
二分图的例子：

    A ─── X
    │     │
    B ─── Y
    │
    C ─── Z

左集合：{A, B, C}
右集合：{X, Y, Z}
所有边都连接左和右，没有边连接同侧顶点。
```

二分图的典型应用场景：

- **相亲匹配**：男性和女性各为一个集合，连线表示可能配对
- **任务分配**：员工和任务各为一个集合，连线表示能胜任
- **课程安排**：老师和教室各为一个集合，连线表示可用

### 1.2 染色法（BFS / DFS）

判定一个图是否为二分图的方法是**染色法**：

1. 从任意顶点开始，将它染成黑色
2. 将它的所有邻居染成白色
3. 对每个白色顶点，将它的邻居染成黑色
4. 如果在染色过程中发现某个顶点需要同时染成两种颜色（即邻居的颜色与自己相同），说明不是二分图

```python
from collections import deque

def is_bipartite(graph):
    """
    染色法判定二分图
    
    参数:
        graph: 邻接表
    
    返回:
        True 如果是二分图，False 如果不是
    
    算法思路：
        用 BFS 逐层染色。
        color[u] = 0 表示未染色，1 和 -1 表示两种颜色。
        相邻顶点必须染不同颜色。
        如果有冲突，则不是二分图。
    """
    n = len(graph)
    color = [0] * n              # 0: 未染色, 1: 黑色, -1: 白色

    for start in range(n):
        if color[start] != 0:
            continue             # 已染色，跳过

        # 从 start 开始 BFS 染色
        color[start] = 1         # 起点染黑色
        queue = deque([start])

        while queue:
            u = queue.popleft()

            for v in graph[u]:
                if color[v] == 0:
                    # 邻居染成相反颜色
                    color[v] = -color[u]
                    queue.append(v)
                elif color[v] == color[u]:
                    # 邻居颜色相同 → 冲突，不是二分图
                    return False

    return True
```

DFS 版本的实现思路完全相同，只是用递归代替队列：

```python
def is_bipartite_dfs(graph):
    """DFS 染色法判定二分图"""
    n = len(graph)
    color = [0] * n

    def dfs(u, c):
        color[u] = c
        for v in graph[u]:
            if color[v] == 0:
                if not dfs(v, -c):
                    return False
            elif color[v] == c:
                return False
        return True

    for i in range(n):
        if color[i] == 0:
            if not dfs(i, 1):
                return False
    return True
```

## 2 匈牙利算法（选读）

### 2.1 增广路径

匈牙利算法用于求解**二分图的最大匹配**问题——找到最多的边，使得没有两条边共享同一个顶点。

核心概念是**增广路径**：从未匹配的左顶点出发，沿着"未匹配→匹配→未匹配→匹配→…"交替走，最终到达一个未匹配右顶点的路径。

```
增广路径示例（虚线 = 未匹配，实线 = 匹配）：

    A      B      C
   / \    /
  X   Y  Z

从 A 出发 → X（未匹配）→ B（已匹配 X）→ Y（未匹配）
找到增广路径 A-X-B-Y，可以增加匹配数。
```

### 2.2 最大匹配

```python
def hungarian(graph, n_left, n_right):
    """
    匈牙利算法求二分图最大匹配
    
    参数:
        graph: 左顶点到右顶点的邻接表，graph[u] = [v1, v2, ...]
        n_left: 左顶点的数量
        n_right: 右顶点的数量
    
    返回:
        match_right: 左顶点匹配到的右顶点（-1 表示未匹配）
        match_left: 右顶点匹配到的左顶点（-1 表示未匹配）
        max_match: 最大匹配数
    
    算法思想：
        遍历每个左顶点，尝试为其寻找增广路径。
        如果能找到，匹配数加 1。
        增广路径的寻找用 DFS 实现。
    """
    match_left = [-1] * n_right          # 右顶点匹配到的左顶点
    match_right = [-1] * n_left          # 左顶点匹配到的右顶点

    def dfs(u, visited):
        """
        尝试为左顶点 u 寻找增广路径
        visited: 记录在本次尝试中已访问的右顶点
        """
        for v in graph[u]:
            if visited[v]:
                continue
            visited[v] = True

            # 如果 v 未匹配，或者能为 v 的匹配对象找到新的匹配
            if match_left[v] == -1 or dfs(match_left[v], visited):
                match_left[v] = u
                match_right[u] = v
                return True
        return False

    max_match = 0
    for u in range(n_left):
        visited = [False] * n_right
        if dfs(u, visited):
            max_match += 1

    return match_right, match_left, max_match
```

```python
from collections import deque

def is_bipartite_graph(n, edges):
    """
    判定无向图是否为二分图
    
    参数:
        n: 顶点数
        edges: 边列表 [(u, v), ...]
    """
    graph = [[] for _ in range(n)]
    for u, v in edges:
        graph[u].append(v)
        graph[v].append(u)

    color = [0] * n

    for start in range(n):
        if color[start] != 0:
            continue

        color[start] = 1
        queue = deque([start])

        while queue:
            u = queue.popleft()
            for v in graph[u]:
                if color[v] == 0:
                    color[v] = -color[u]
                    queue.append(v)
                elif color[v] == color[u]:
                    return False
    return True
```

## 本章小结

- **二分图**的顶点可以分成两个集合，所有边都连接不同集合
- **染色法**用 BFS/DFS 给顶点交替染色，遇冲突则不是二分图
- **判定条件**：一个图是二分图当且仅当它不含奇数环
- **匈牙利算法**用于求解二分图的最大匹配，核心是寻找增广路径
- 二分图的应用：匹配问题、任务分配、课程安排等
