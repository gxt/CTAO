## 2.1b 如何复制内容

### 为什么 Ctrl+C 不管用？

在终端的世界里，`Ctrl+C` 通常被用作**中断信号**，而不是复制快捷键。

- **在 Word 里**：`Ctrl+C` = 复制内容
- **在终端里**：`Ctrl+C` = 中断

### 方法一：鼠标流（最直觉）

1. **按下鼠标左键**，拖动选择文字
2. **松开鼠标左键**
3. **完成！** 自动复制到剪贴板

### 方法二：键盘流（最快）

1. 按下 **Leader 键**（默认 Ctrl+X）
2. 松开所有键
3. 按下 **Y**（Y = Yank，程序员的黑话）

### 方法三：命令流（最全）

输入 `/copy`，整个对话历史就会被完整复制。

### 故障排查：屏幕出现乱码

**原因**：Ctrl+C 在 Windows 上是暴力强制退出信号，导致 OpenCode 还没来得及关闭鼠标监听就被杀死。

**解决方法**：
- **急救**：直接关闭当前终端窗口
- **预防**：不要用 Ctrl+C 退出，请使用 **Ctrl+D**

## 2.1c AI 的基础工具

OpenCode 配了 **10 个核心工具**，本课重点讲 6 个最常用的文件操作工具：

| 工具 | 干什么 | 类比 |
|------|--------|------|
| **read** | 读取文件或目录 | 打开文件看内容 |
| **write** | 创建或覆盖文件 | 另存为 |
| **edit** | 精确替换文件中的文本 | 查找替换 |
| **bash** | 执行 Shell 命令 | 在终端敲命令 |
| **grep** | 按内容搜索文件 | 全局搜索 |
| **glob** | 按文件名搜索文件 | 文件管理器里搜文件名 |

### read 工具

- 基本参数：filePath、offset、limit
- 大文件处理：超过 2000 行自动截断
- 特殊文件：能读取图片和 PDF，转成 base64 发给 AI

### write 工具

- 创建新文件或覆盖已有文件
- **"先读后写"规则**：如果文件已存在，必须先 read 再 write

### edit 工具

- 用字符串匹配来精确定位要修改的位置
- **9 层匹配策略**：从精确匹配到上下文感知
- 多处匹配：用 `replaceAll` 或提供更多上下文

### bash 工具

- 执行 Shell 命令（跑测试、装依赖、查看 Git 状态）
- **不要用 bash 做文件操作**：专用工具有权限检查和智能容错

### grep 和 glob

- **grep**：搜索文件内容（最多 100 条结果）
- **glob**：搜索文件名（最多 100 条结果）

## 2.1d 使用图片与 AI 对话

### 三种方式让 AI 看到图片

1. **粘贴截图**（最常用）：截图后直接 Ctrl+V
2. **引用本地文件**：用 `@图片路径`
3. **AI 生成图片**：部分模型支持

### 各平台截图方法

| 系统 | 区域截图 | 全屏截图 |
|------|---------|---------|
| Windows | Win + Shift + S | PrtScn |
| Mac | Cmd + Shift + 4 | Cmd + Shift + 3 |
| Linux (GNOME) | PrtScn 选区域 | PrtScn |

### Linux 用户

需要安装剪贴板工具：

```bash
# X11
sudo apt install xclip

# Wayland
sudo apt install wl-clipboard
```

### 模型支持情况

**国际模型**：GPT-5.2、Claude 4.6、Gemini 3.1 等支持图片

**国内模型**：
- ✅ **Kimi K2.5** 支持图片
- ❌ GLM-5、MiniMax 2.5、DeepSeek、豆包、通义千问不支持

## 2.2 管理对话

### 新建会话

- 命令：`/new`
- 快捷键：`Ctrl+X N`

- 用方向键在侧栏选择
- 或用 `/sessions` 命令

- 命令：`/undo` 撤销 AI 的最后一条回复

### 导出对话

- 命令：`/copy` 复制整个对话
- 命令：`/export` 导出为 Markdown

## 2.6 Git 入门

### 第一次提交

```bash
# 初始化仓库
git init

# 添加文件
git add .

# 提交
git commit -m "first commit"

# 关联远程仓库
git remote add origin https://github.com/xxx/xxx.git

# 推送
git push -u origin main
```

### OpenCode 中使用 Git

让 AI 帮你操作 Git：

```
帮我初始化 git 仓库并提交当前文件
```
